# 책별 표지 색 (측정값)

홈페이지 책 목업과 책별 상세 페이지의 색을 정하기 위해, 한국어 초판 표지에서 픽셀을 측정해 뽑은 값입니다.
**색값만 적었고 표지 이미지 파일은 저장소에 없습니다.** (표지 사용은 출판사 허락 전)

## 측정 방법

- 알라딘 상품 페이지의 표지 이미지(폭 500px)를 내려받아 측정했습니다.
- 가장자리 3%, 우측 하단(알라딘 뱃지·띠지가 앉는 자리)을 빼고 픽셀 약 4만 개를 8색으로 묶었습니다(k-means). 비율이 큰 색부터 보고, 진한색·중간색·밝은 포인트를 골랐습니다.
- 바탕 그라데이션은 표지를 세로 5구간으로 나눠 구간별 중앙값을 잰 뒤, 위→아래 순서로 2~3색을 골랐습니다.
- 서점 이미지는 압축과 보정이 들어가 실물 인쇄색과 조금 다를 수 있습니다. 실제 인쇄색은 출판사 파일을 받으면 확인합니다.

## 색마다 어디에 쓰인 색인지

- **쇼코의 미소:** 진한색은 인물 머리카락과 글자. 나머지는 흰색에서 연분홍·연보라로 번지는 바탕.
- **내게 무해한 사람:** 진한색은 인물 그림자·머리카락(면적 1%). 중간색은 위쪽 번지는 노랑 면, 포인트 2는 아래 하늘색 띠.
- **밝은 밤:** 진한색은 제목 글자의 청록. 중간색은 아래 바다 하늘색. 위에서 아래로 연보라 → 분홍 → 살구 → 하늘색.
- **애쓰지 않아도:** 일러스트 표지. 진한색은 산과 인물의 먹색, 중간색은 물빛 파랑. 소량(3%) 포인트로 황토색 `#BD853E`가 있습니다.
- **아주 희미한 빛으로도:** 진한색은 사진 위쪽의 청남색, 포인트는 아래 살구색 띠. (이전에 홈페이지에 쓴 검정·파랑 값 `#1B2A36`·`#3E5870`은 눈대중이었고, 이 측정값이 더 정확합니다.)
- **백지 앞에서:** 표지 대부분이 거의 흰색(`#F3F3F3`)이고 제목 글자가 연회색입니다. 진한색에 해당하는 색이 표지에 없어 제목 글자색 `#B1B1B1`을 적었습니다. 글자색으로 쓰면 대비가 부족하므로, 본문 글자는 `#1F3A4D` 같은 기존 먹색을 쓰는 편이 안전합니다.

## 쓸 때 주의

- 6권 중 4권(쇼코·무해한·밝은 밤·백지)은 중간색이 연한 파스텔이라 **글자색으로 쓰면 대비 4.5:1이 나오지 않습니다.** 면·그라데이션·띠 같은 배경 용도로만 쓰고, 글자는 먹색을 유지하세요.
- 쇼코의 미소·내게 무해한 사람 이미지는 알라딘의 수상 뱃지·띠지가 같이 찍힌 상품 이미지입니다. 해당 영역은 측정에서 뺐습니다.
- 『밝은 밤』은 같은 알라딘 검색에 3권 세트 이미지도 나왔는데, 세트 이미지는 쓰지 않고 단행본 이미지만 측정했습니다. 『아주 희미한 빛으로도』도 세트(다른 책 포함) 이미지는 제외했습니다.
- 표지 서체명은 이미지로는 알 수 없어 적지 않았습니다. 출판사에 문의가 필요합니다.
