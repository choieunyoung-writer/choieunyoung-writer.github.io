# Land-book 참고 사이트와 팔레트 점검

작성: 2026-10-17. 이미지 파일은 올리지 않았고 설명과 링크만 적었습니다.

## 1. Land-book에서 고른 첫 화면 6곳

**먼저 알아둘 점:** Land-book(land-book.com)에는 문학·작가·서점 사이트가 많지 않습니다. 검색이 제목 위주라 `author`, `publisher`, `writer`, `journal`, `translator`, `reading` 등으로 찾은 것 중 쓸 만한 6곳을 골랐습니다. 한국어 작가 사이트는 없었습니다. 6곳 중 3곳(Matt Porterfield·Sabzian·Current)은 문학이 아니라 영화인·영화 저널·읽기 앱이라, 구조와 분위기 참고용입니다. 사이트는 2026-10-17에 1440×900 headless 브라우저로 열어 첫 화면을 직접 봤습니다(Land-book 썸네일 기준이 아님). Princeton University Press(Cloudflare 보안 확인으로 첫 화면 확인 불가)와 번역가 개인 사이트(alexandraperles.com, 빈 화면)는 제외했습니다.

### 6곳에서 공통으로 가져올 점

- 첫 화면은 **이름 또는 신간 하나**만. 메뉴는 4~6개.
- 책 정보는 **글로 먼저** 성립하게(제목·연도·한 줄·"view book" 링크), 이미지는 얹는 것.
- 배경색을 넓게 쓰는 사이트(Morgenmete·Sabzian)는 **글자를 면 위에 직접 얹지 않고** 별도 띠·카드 위에 둡니다.

### 렌더링해서 본 것

흰 바탕에 책별 그라데이션 띠(150px)를 세우고 이름·메뉴를 얹어 봤습니다.

- 흰 글자 이름은 쇼코·백지에서 **거의 안 보이고**, 무해한(노랑)·밝은 밤(연보라)에서도 약합니다.
- 포인트 파랑 메뉴는 희미한 빛(진한 청남색 위)에서 **거의 안 보입니다**(1.1).
- 반대로 먹색 이름·메뉴는 희미한 빛 위에서 안 보입니다(2.0).
- 6개 그라데이션은 서로 뚜렷하게 구별됩니다(분홍·노랑/하늘·살구·청록/파랑·청남/살구·연회색/파랑).

### 바꿀 점

1. **이름과 메뉴 글자색을 책 색에 맞춰 자동 전환합니다.** 위쪽이 연한 5권(쇼코·무해한·밝은 밤·애쓰지·백지)은 먹색 `#1F2430`, 위쪽이 진한 『아주 희미한 빛으로도』만 흰색 `#FFFFFF`(7.8). 한 가지 글자색으로 전부 덮으려 하지 않는 것이 핵심입니다.
2. **희미한 빛 위의 포인트색(메뉴 현재 표시 밑줄 등)은 연한 파랑으로 바꿉니다.** `#A9C8F0`이 그 자리에서 4.5입니다. 흰 글자 + 밑줄로 가는 쪽이 더 단순합니다.
3. **포인트 `#164C8B`는 흰 바탕과 쇼코·무해한·백지 위에서만** 글자색으로 씁니다. 밝은 밤(4.1)·애쓰지(2.9)의 중간색 면 위에서는 글자로 쓰지 않습니다.
4. **책 목업 안 [작품명] 라벨**(12.5px)은 파스텔 3권에서 4.5 미달이라 먹색 100%로 하고, 어두운 번짐 위에 앉지 않게 위치를 옮기거나 번짐을 약하게 합니다. (화면 점검 결과는 별도 전달)
5. **구분선 `#E9E3DF`(1.27)는 장식선 전용**으로 둡니다. 입력칸·버튼 테두리에는 `#8A93A5`(흰 바탕 3:1 이상) 같은 더 진한 선을 씁니다.
6. 중간색 4권(쇼코·무해한·밝은 밤·백지)과 애쓰지는 **글자색으로 쓰지 않는다**는 규칙을 코드 주석이나 스타일 변수 이름(`--cover-*-fill`)으로 남겨 실수를 막습니다.
